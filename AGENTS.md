# Agent Instructions

## Local Environment

- Python is installed locally on this machine.
- Use the Conda environment named `pyg` for Python commands in this repository.
- When running Python-related commands, prefer:

```powershell
conda activate pyg
```

## Notes

- Assume Python dependencies needed for this project should be checked in the `pyg` environment first.
- If a command behaves differently across environments, prefer the `pyg` environment as the default runtime.
