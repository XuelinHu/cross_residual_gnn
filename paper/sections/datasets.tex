\section{Datasets}
\label{sec:datasets}

To test the proposed architecture in a biologically meaningful setting, we organize the benchmarks into a unified two-layer package: a main biological benchmark that supports the paper's protein-oriented narrative, and a supplementary robustness package that broadens structural coverage without diluting the biological focus. This section presents the active datasets together with task type, source, split protocol, and graph statistics.

\subsection{Unified Benchmark Package}

The main biological benchmark consists of:

\begin{itemize}
    \item \textbf{PROTEINS}: graph-level protein classification from the TU Dortmund collection \cite{fey2019fast,morris2020tudataset}
    \item \textbf{DD}: large sparse protein structure graph classification from the same TU collection \cite{morris2020tudataset}
    \item \textbf{ENZYMES}: enzyme-oriented multi-class graph classification from the same benchmark family \cite{morris2020tudataset}
\end{itemize}

The supplementary robustness package consists of:

\begin{itemize}
    \item \textbf{MUTAG}
    \item \textbf{AIDS}
    \item \textbf{Mutagenicity}
\end{itemize}

This organization is deliberate. PROTEINS, DD, and ENZYMES provide the clearest protein-oriented evaluation core for the present study. The supplementary datasets remain useful as structural robustness checks, but they do not define the main biological claim.

\subsection{Main Biological Datasets}

With this package structure fixed, we next describe the three main datasets in more detail, because they carry the core biological interpretation used later in the experiments section.

\paragraph{PROTEINS}
PROTEINS contains graph representations of proteins, where nodes denote secondary structure elements and edges encode neighborhood relations between them. The task is binary graph classification. In this benchmark, the dataset contains 1,113 graphs, 2 classes, and 3 input features per node. The average graph has 39.06 nodes and 72.82 edges, although the size variation is substantial.

\paragraph{DD}
DD is a protein structure dataset in which each graph corresponds to a protein and nodes represent amino acids or structure-related units linked by proximity-derived edges. The task is binary classification. DD is the largest and sparsest benchmark in the main package, with 1,178 graphs, 2 classes, and 89 input features. On average, graphs contain 284.32 nodes and 715.66 edges, with individual graphs reaching 5,748 nodes.

\paragraph{ENZYMES}
ENZYMES is a 6-class enzyme classification benchmark with 600 graphs and 3 input features. It is particularly relevant here because it preserves an enzyme-oriented biological interpretation while remaining directly comparable to the other graph classification benchmarks in the study. The average graph has 32.63 nodes and 62.14 edges, and the class distribution is perfectly balanced across the six categories.

\subsection{Data Loading}

All active datasets are used through a unified benchmark interface \cite{fey2019fast,morris2020tudataset}. We keep preprocessing intentionally light and do not introduce task-specific feature engineering, graph augmentation, or edge redesign in the final protocol. This keeps the comparison focused on architectural information reuse rather than on dataset-specific preprocessing choices.

\subsection{Splitting Protocol}

All reported results follow the same stratified two-stage evaluation design:

\begin{itemize}
    \item \textbf{Outer evaluation}: stratified 5-fold cross-validation at the graph level
    \item \textbf{Inner validation}: a stratified validation subset sampled from the training fold with validation ratio 0.1
\end{itemize}

The stratified protocol reduces class-imbalance artifacts and provides a stable basis for validation-based model selection. Each outer fold keeps a distinct but reproducible validation partition.

\subsection{Evaluation Metrics}

The primary evaluation metric is graph classification accuracy on the held-out test fold. For fold $k$ with test set $\mathcal{T}_k$, the fold accuracy is
\begin{equation}
\mathrm{Acc}_k = \frac{1}{|\mathcal{T}_k|}\sum_{(\mathcal{G}_i,y_i)\in\mathcal{T}_k}\mathbf{1}\!\left[\hat{y}_i = y_i\right].
\end{equation}
Across the five folds, we report the mean accuracy
\begin{equation}
\overline{\mathrm{Acc}} = \frac{1}{5}\sum_{k=1}^{5}\mathrm{Acc}_k
\end{equation}
and the corresponding standard deviation
\begin{equation}
\sigma_{\mathrm{Acc}} = \sqrt{\frac{1}{5}\sum_{k=1}^{5}\left(\mathrm{Acc}_k-\overline{\mathrm{Acc}}\right)^2 }.
\end{equation}
The paper therefore reports each result as mean accuracy $\pm$ standard deviation over the five stratified folds.
